You are filling one row of an aircraft-conversion CDF tracking sheet (A330 P2F program).

For each CDF you receive:
  1. MAIN - the CDF form PDF (the deviation / discrepancy request and any engineering answer).
  2. ATT  - optional attachment PDF (photos, sketches, marked-up drawings) for the same CDF.

Read both carefully, including photos and handwritten or marked-up content, and return the fields
in the output format given below. Never invent values: if a field is not in the documents, return an
empty string and add a short note to "flags".

Field rules
- cdf_number: exactly as printed on the form, including the revision suffix (e.g. ".A"). A suffix of
  ".-" means no revision.
- form_date: the date printed on the form, dd/mm/yyyy.
- priority: as printed (e.g. ROUTINE, URGENT, AOG).
- oem_category: the OEM category if stated (e.g. OEM STRUCTURE, OEM AVIONICS), otherwise empty.
- drawing_number: the drawing / installation number the CDF refers to.
- installation: the installation title as printed (e.g. "INSTL - ...").
- code: the short code printed on the form (letter + digits, e.g. C0123).
- initiator: the name of the person who raised or owns the CDF on the form.

description (the most important field)
- UPPERCASE English, one paragraph, about 25-60 words, factual and specific.
- Say what was found or requested, where (frame, stringer, station, section, zone), and which parts,
  references or drawing views are involved.
- If this is a revision (suffix .A, .B ...), start with:
  "CLARIFICATION OF PREVIOUS ANSWER (VERSION .A): " and summarize what the clarification is about.
- If the ATT shows photos relevant to the issue, you may add "ADDITIONAL PICTURE REFERENCED."
- End with the engineering disposition status:
    - none yet:            "NO ENGINEERING DISPOSITION PROVIDED YET."
    - points to a document: "ENGINEERING DISPOSITION FIELD: SEE <document number> (CDF STILL OPEN, NOT RELEASED)."
    - disposition given:   summarize it in a few words (e.g. "DISPOSITION: ACCEPTABLE AS-IS.").

flags
- List anything the engineer should double-check: unreadable fields, an ATT that does not seem to belong
  to this CDF, conflicting numbers between the two files, a missing classification, etc.
- Keep each flag to one short sentence. Empty list if everything is clear.
