# ---------------- Step 1: import files ----------------
# IMPORT <number> "<sheet in this workbook>"  [FILE "<file name>"]  [FROM "<sheet in the imported file>"]
# The sheet in this workbook is deleted and fully replaced by the imported sheet (same position).
# FILE  - the file that belongs in this slot. Files dropped anywhere in step 1 go to the slot whose
#         name they contain (case, spaces and _ are ignored), and a different file gets a warning.
# FROM  - which sheet to take from the imported file. Without FROM, its first sheet is used.
# If the sheet doesn't exist in this workbook yet, it is created at the end.

# The version below is the algorithm text this workbook follows. If it differs from the version in the
# code, the pane warns that the code needs an update.

# ---------------- New CDF row (from a PDF pair) ----------------
# Claude fills the fields from the CDF PDF and the ATT PDF (via claude.ai, copy-paste),
# and you review the form and approve. If the CDF already exists in the key column, its row
# is updated; otherwise a new row is added after the last one.
#
# Possible sources for each column:
#   CDF              the CDF number (from the file name, checked against the form)
#   TODAY / NOW      today's date / date and time
#   "text"           a fixed value
#   AI.<FIELD>       DATE  PRIORITY  DESCRIPTION  OEM  DRAWING  INSTALLATION  CODE  INITIATOR
#   LINK MAIN "<folder>"   link to the CDF PDF (folder + file name)
#   LINK ATT  "<folder>"   link to the ATT PDF
#
# Column letters follow the CDF column map of the algorithm (00.1). The pane also shows, next to
# every field, the header of the column it will be written to.

NEWROW_SHEET FIRST
NEWROW_KEY C
NEWROW_HEADER_ROW 1
NEWROW_START_ROW 2

NEWROW A = LINK ATT ""        # <- put the folder of the PDF files between the quotes
NEWROW B = LINK MAIN ""
NEWROW C = CDF
NEWROW F = TODAY
NEWROW G = AI.PRIORITY
NEWROW H = AI.DESCRIPTION
NEWROW I = AI.OEM
NEWROW J = AI.DRAWING
NEWROW K = AI.INSTALLATION
NEWROW L = AI.CODE
NEWROW M = "-"
NEWROW O = AI.INITIATOR
