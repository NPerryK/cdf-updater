# CDF Updater 2 — settings
# The add-in no longer runs the CDF algorithm (that runs on an online model). It replaces sheets, adds rows by hand,
# shows and presents the status, paints the sheet's look and links with My Notes. Lines starting with # are notes.

# ---- which file replaces which sheet: a file goes to the sheet whose HEADERS are all in one of its first rows.
#      FILE is a fallback: part of the file name, used only when the headers don't match.
#      Sheet CDF is the algorithm's: it isn't replaced here.
IMPORT "Mantra"     HEADERS "Doc ID" "Date Status" "Pending To Emp"  FILE "650"
IMPORT "GCC"        HEADERS "CDF Number" "Current Station"      FILE "CDF_List_Export"
IMPORT "MANTRAREV"  HEADERS "Doc ID" "Release Date"             FILE "MANTRAREV"

# ---- rows added by hand (ROWS page)
ROWS_SHEET "CDF"
ROWS_KEY C              # the column with the CDF number
ROWS_HEADER_ROW 1
ROWS_START_ROW 2
ROWS_COLUMNS A:AH       # pasted values outside these columns are left out

# ---- the log of every change the add-in makes
LOG "UPDATE LOG"

# ---- the status
EXCLUDE "A330-1-052 (another)"   # a known duplicate: not counted (as in CDF STATUS)
STUCK_DAYS 14                    # "Not moving": at the same station longer than this
# TARGET OPEN 150 BY 2026-12-31  # a goal line on "Open CDFs over time" (remove the # to use it)
